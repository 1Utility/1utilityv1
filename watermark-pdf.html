How it works

Your chosen text is drawn diagonally across the center of every page, at the size, color, and opacity you set — the same visual pattern used for "DRAFT" or "SAMPLE" stamps on documents. Lower opacity keeps the underlying content fully readable; higher opacity makes the watermark more prominent.

What this is — and isn't — good for

This is a visible deterrent and labeling tool, useful for marking drafts or discouraging casual redistribution. It is not a security or access-control feature — the watermark can be cropped or edited out by someone with PDF editing software, so don't rely on it to protect genuinely sensitive content.

Frequently Asked Questions

Can I change the watermark's angle or position?
The watermark is placed diagonally across the center of each page automatically; the current version doesn't support custom angles or positions.
Will the watermark cover important content?
Lower opacity settings keep underlying text and images fully readable through the watermark — start around 20-25% opacity for a subtle mark that doesn't obscure content.
Can this be removed from the PDF later?
Yes, with PDF editing software — this is a visible label, not an access-control or security feature.
Is my file uploaded anywhere?
No — the watermark is applied entirely in your browser using JavaScript. Nothing is sent to a server.
