How compression works here — and its real limits

This tool rebuilds the PDF's internal object structure more efficiently (merging duplicate objects and using more compact internal storage), which meaningfully shrinks PDFs generated from Word, PowerPoint, or similar software with a lot of repeated formatting data. Being upfront about what it doesn't do: it does not re-compress or downsample embedded images, which is where most of the file size lives in scanned documents or photo-heavy PDFs. For a PDF that's mostly scanned pages, expect a modest reduction at best.

If your PDF is mostly scanned images

The most effective way to shrink an image-heavy PDF is to reduce the resolution of the images themselves before they become a PDF — for example, using PDF to Images, resizing those images with an image tool, then rebuilding with Images to PDF.

Frequently Asked Questions

Why didn't my file size change much?
If your PDF is mostly scanned pages or photos, most of its size comes from image data this tool doesn't re-encode. Text-heavy documents with formatting (from Word, PowerPoint exports, etc.) typically see a larger reduction.
Will compression reduce quality?
No — this method doesn't alter text or images at all, it only makes the file's internal storage more efficient. What you see is unchanged; only the file size differs.
Is there a guaranteed compression percentage?
No — results depend entirely on the specific PDF's internal structure. Some files shrink significantly, others barely change.
Is my file uploaded anywhere?
No — compression happens entirely in your browser using JavaScript. Nothing is sent to a server.
