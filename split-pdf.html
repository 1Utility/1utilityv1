How page ranges work

Enter ranges separated by commas — each range becomes its own downloadable PDF. 1-3, 4-6, 7-10 on a 10-page document produces three files: pages 1 through 3, pages 4 through 6, and pages 7 through 10. A single page number on its own (like 5) produces a one-page file.

Common reasons to split a PDF

Pulling one chapter out of a long e-book, separating individual invoices that were scanned together into one file, or breaking a large report into per-section documents for different reviewers are the most common cases — anywhere a single combined file needs to become several standalone ones.

Frequently Asked Questions

What happens if my ranges overlap or skip pages?
Overlapping ranges simply produce overlapping content across the output files — that's allowed if you want the same page in two files. Skipped pages are just left out of every output file; they aren't deleted from anything, since the original file isn't modified.
Can I see which page is which before splitting?
Yes — every page renders as a thumbnail with its page number before you enter any ranges, so you can confirm exactly which pages you're selecting.
Does splitting reduce file size?
Each output file will roughly be its proportional share of the original size, since pages aren't recompressed — for full size reduction, use the Compress PDF tool on the result.
Is there a page count limit?
No limit is enforced by the tool; very large PDFs (hundreds of pages) may take a few seconds longer to render thumbnails, but will still process.
Will my file be uploaded anywhere?
No — splitting happens with JavaScript directly in your browser tab. Nothing is sent to a server.
