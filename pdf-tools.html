Why local processing matters

Most online PDF tools work by uploading your file to a server, processing it there, and sending the result back — which means your document, even briefly, sits on infrastructure you don't control. These tools instead run the entire operation as JavaScript inside your browser tab. The PDF never leaves your device, there's no upload wait, and closing the tab clears everything completely. The tradeoff is that very large files (hundreds of megabytes) may process more slowly than a dedicated server would, since you're using your own device's processing power rather than a data center's.

Frequently Asked Questions

Do I need to create an account?
No — every tool works immediately with no sign-up, and there's no limit on how many times you can use them.
Is there a file size limit?
No limit is enforced by the tools themselves. In practice, very large files are bounded by your device's available memory rather than any restriction we impose.
Are my files really not uploaded anywhere?
Correct — all processing uses JavaScript libraries (pdf-lib and pdf.js) running directly in your browser. You can disconnect from the internet after the page loads and the tools will still work.
Why do some tools say "Soon"?
We're rolling these out individually to make sure each one is genuinely solid before publishing it, rather than launching everything at once with rough edges.
