How it works

Each image becomes its own page in the output PDF, sized to fit the page while preserving its original proportions. Drag thumbnails to set the order pages should appear in before creating the file — the same drag-to-reorder pattern used across our PDF tools.

Common uses

Combining scanned receipts into one PDF for an expense report, turning photographed pages of a document into a single shareable file, or assembling a set of photos into one PDF for printing are the most common reasons people need this.

Frequently Asked Questions

Which image formats are supported?
JPG and PNG. If you have images in other formats, they'll need to be converted first.
Can I mix JPG and PNG in the same PDF?
Yes — you can add any combination of JPG and PNG files, and they'll all be combined into the same output PDF.
Will image quality be reduced?
Images are placed into the PDF at their original resolution — there's no forced compression, though very high-resolution images will make for a larger PDF file.
Is there a limit on how many images I can add?
No hard limit is enforced; the practical ceiling is your device's available memory when working with a very large number of high-resolution images.
Is my file uploaded anywhere?
No — everything happens locally in your browser using JavaScript. Nothing is sent to a server.
