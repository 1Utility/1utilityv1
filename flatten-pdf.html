What "flattening" means

A fillable PDF form has interactive fields — text boxes, checkboxes, dropdowns — that anyone opening the file can still edit. Flattening permanently converts whatever was entered into those fields into fixed page content, the same way text looks once printed and scanned back in. After flattening, the values are locked in place and the form fields no longer exist to be edited.

Important limitation

This is different from PDF password protection or encryption — flattening prevents editing the *form fields* specifically, but doesn't encrypt the file or restrict opening/printing/copying it. Someone could still potentially alter the flattened text using PDF editing software; this tool locks the form-field structure, not the document as a whole.

Frequently Asked Questions

Does this add a password to my PDF?
No — flattening locks the form fields specifically. It doesn't encrypt the file or prevent it from being opened or edited with dedicated PDF editing software.
What happens if my PDF has no fillable form fields?
The tool will report there was nothing to flatten — the file already behaves as a fixed document with no interactive fields to lock.
Will the visual appearance of the form change?
No — the entered values look identical after flattening; only their underlying editability changes.
Is my file uploaded anywhere?
No — flattening happens entirely in your browser using JavaScript. Nothing is sent to a server.
